# 🖼️ Deepfake Image Detection System
MINOR PROJECT

A web-based Deep Learning application that detects whether an uploaded image is **Real** or **Deepfake** using the **EfficientNet-B4** model.

## 🚀 Features

- Detect Real vs Deepfake images
- Built with EfficientNet-B4
- Flask-based web application
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- PyTorch
- EfficientNet-B4
- OpenCV
- NumPy
- HTML/CSS

## 📦 Installation

```bash
git clone https://github.com/sakshibaghel2006/Deepfake_Image_Detection_System.git
cd Deepfake_Image_Detection_System
pip install -r requirements.txt
python app3.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

## 📌 Note

The trained model (`best_model.pth`) is not included because it exceeds GitHub's file size limit. You can train the model using `train_efficientnet_b4.py`.
